# 主線劇本（the spine）

跟著「一輪中的位置」與「境界」走的台詞：序幕、局規、求敗每局之後的話、收局、終局、夢醒，以及韋小寶的一切。這一層從不點出是哪一局、哪一位俠客。

格式：每一行 `〔編號〕` 之後到行尾是可改的文字；編號與編號之前的標籤不可改。詳見 README。

- **旁白**　〔S253〕求敗刻下第三行：「重劍無鋒，大巧不工。」劍尖落得甚輕，只掉了些許石屑。

### 第四重・木劍境界

- **回目**　〔S254〕草木竹石皆可劍
- **石上刻字**　〔S255〕木劍：不滯於物，草木竹石均可為劍
- **旁白**　〔S256〕少年在燈下一個個數過身邊的人。
- **無名**　〔S257〕老伯問我怎麼不挑人，我說來的都是朋友。本人也好，拓來的也好，都一樣。各位怎麼想？
- **旁白**　〔S258〕第四行是木劍：「不滯於物，草木竹石均可為劍。」刻罷，求敗把劍橫在膝頭，沒有收起。

### 第五重・無劍境界

- **回目**　〔S259〕無劍猶握一枰棋
- **石上刻字**　〔S260〕最後一行，他沒有刻
- **旁白**　〔S261〕想起求敗說這是最後一盤，少年在燈下把眾人的臉一張張看過，像要記牢些。
- **無名**　〔S262〕下完各位歸本尊，我回被窩。醒了怕要忘，各位別怪。各位說是拓來的，心裡怎麼想？
- **旁白**　〔S263〕石上還餘一行空處，求敗提劍看了看，卻把劍輕輕放到石旁。那一行終究空著。

### 各境界共用

- **旁白**　〔S264〕這輪棋未下完，石上也未添字。

## 夢醒

> 一輪結束，少年醒來。先接 CLOSING 一句（勝：請回吧；敗：盒蓋合上），再接按境界取的一段 FRAGMENTS（第一段為第一重境界）。

- **旁白**　〔S265〕耳邊那聲「請回吧」未散，少年已醒。
- **旁白**　〔S266〕耳邊合盒的聲音未散，少年已醒。

### 第一重・利劍境界

- **旁白**　〔S267〕一條濕熱的舌頭正舔著他的臉，是家裡的狗。谷中只剩一張棋臺、一個老人的模糊影子，手指卻還拈著，彷彿那枚子尚未落下。

### 第二重・軟劍境界

- **旁白**　〔S268〕鍋鏟嚓嚓碰著鐵鍋，飯香從灶前飄來，娘正忙著做飯。他拾起灶邊一根柴枝，手腕一抖，竟挽出個劍花。

### 第三重・重劍境界

- **旁白**　〔S269〕娘喊他起身，那名字聽了十幾年，這時卻有些生疏，像是夢裡一直有人叫他另一個名字。他到屋後翻找，找出一柄生鏽的舊劍。

### 第四重・木劍境界

- **旁白**　〔S270〕雞啼聲起，窗紙已白，被窩外頭冷得很。他還想睡回去，把那盤棋下完；磨亮的劍，就擱在枕邊。

### 第五重・無劍境界

- **旁白**　〔S271〕被窩裡那隻手仍握著，彷彿還留著許多人掌心的暖意。他握住枕邊的劍，走出屋去，天尚未亮。
