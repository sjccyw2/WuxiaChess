# 主線劇本（the spine）

跟著「一輪中的位置」與「境界」走的台詞：序幕、局規、求敗每局之後的話、收局、終局、夢醒，以及韋小寶的一切。這一層從不點出是哪一局、哪一位俠客。

格式：每一行 `〔編號〕` 之後到行尾是可改的文字；編號與編號之前的標籤不可改。詳見 README。

## 少年的手記

> 少年在棋臺邊自己瞧明白的事，顯示在手記頁。每條的標題不改。

- **旁白**　〔S228〕棋盒裡的白子黑子，各是一位高手。子一沾棋盤，子上便立起人來。他們都說，來之前那一瞬，自己正走到絕處。開局一把抓起五枚，留下三枚；每勝一局，對面的老伯便再借出一枚白子。
- **旁白**　〔S229〕入了盤的人只瞧得見身邊幾步，盤外的人才瞧得見全局，所以由盤外的人來說往哪裡走。先落的一枚是「眼」；眼破，全盤皆輸。盤上至多五枚白子。倒下的人只是離盤一局，下一局再落。
- **旁白**　〔S230〕他自稱求敗，說自己的姓名早已忘了。這盤棋他左手同右手下了幾百年。黑子是他落的：他落子之時，將一道戰意按在他們眉心，叫他們見人便打。他們不服，卻掙不開。勝了這一局，戰意才散。棋臺上「嗒」的一聲，便是他又落了一子。
- **旁白**　〔S231〕少年醒了便忘，只剩一點影子，手卻記得。對面的老伯一手也沒有忘。那個姓韋的也記得，問他，他就賴。
- **旁白**　〔S232〕少年在已開的最高境界每勝一輪，求敗便在臺邊的石上刻一行字，是他從前一柄劍的來歷。輸掉的一輪，或重下已勝過的境界，石上不添字。
- **旁白**　〔S233〕贏滿十局，同行的人放還本尊。求敗說一聲「好棋」，請少年回去。少年便醒了。
- **旁白**　〔S234〕那個姓韋的每一局都另開一個盤口，押少年贏得出甚麼花樣。押中了分紅：銀子、一卷武譜，或是一場打得太好、叫手自己記起來的仗。對面的老伯瞧不見他，也聽不見他。

## 五重境界

> 每一重境界一組：title 是這一輪的回目；mark 是勝下這一重時求敗在臺邊石上刻的那一行；echo 是夜話時少年的開口；carve 是勝後旁白說他怎樣刻字。NO_MARK：一輪落敗，石上不添字。

### 第一重・利劍境界

- **回目**　〔S235〕深谷一枰逢稚子
- **石上刻字**　〔S236〕利劍：弱冠之前所用
- **旁白**　〔S237〕谷口的月亮，三天沒有動過分毫。
- **無名**　〔S238〕我覺得我是在學劍，只是劍不在我手上。……各位贏了回去，要做甚麼？
- **旁白**　〔S239〕少年臨去回頭，見求敗取過一柄舊劍，在臺邊石上刻了一行字，刻的是他少年時一柄利劍的來歷。刻完，他對著那行字瞧了很久。

### 第二重・軟劍境界

- **回目**　〔S240〕棄劍容易棄子難
- **石上刻字**　〔S241〕軟劍：誤傷義士，棄之深谷
- **旁白**　〔S242〕燈下，少年將求敗那句話又想了一遍。
- **無名**　〔S243〕老伯說各位只是拓下來的一份。我不信一張拓片會口渴、會想家。……各位聽了，惱不惱？
- **旁白**　〔S244〕求敗在石上刻了第二行，刻的是一柄軟劍：誤傷義士，棄之深谷。刻到「棄」字，他的手停了一停。

### 第三重・重劍境界

- **回目**　〔S245〕始聞盤上不平聲
- **石上刻字**　〔S246〕重劍：重劍無鋒，大巧不工
- **旁白**　〔S247〕燈下，少年望了望棋臺那邊。求敗閉著眼，眉頭卻沒有鬆開。
- **無名**　〔S248〕適才那位對手說，那念頭不是他的。老伯頭一回抬頭瞧了他一眼。……各位給人拓了來，惱不惱？
- **旁白**　〔S249〕求敗在石上刻了第三行，刻的是一柄重劍：重劍無鋒，大巧不工。這一行他刻得極輕，石屑也沒有落下多少。

### 第四重・木劍境界

- **回目**　〔S250〕草木竹石皆可劍
- **石上刻字**　〔S251〕木劍：不滯於物，草木竹石均可為劍
- **旁白**　〔S252〕燈下，少年數了數身邊的人。
- **無名**　〔S253〕老伯問我，怎地抓著誰便用誰。我說，來的都是好朋友，哪有得揀的。……各位是拓來的也好，是本人也好，我一樣當各位是朋友。
- **旁白**　〔S254〕求敗在石上刻了第四行，刻的是一柄木劍：不滯於物，草木竹石均可為劍。刻罷，他將那柄刻字的劍橫在膝上，沒有收起。

### 第五重・無劍境界

- **回目**　〔S255〕無劍猶握一枰棋
- **石上刻字**　〔S256〕最後一行，他沒有刻
- **旁白**　〔S257〕燈下，少年將每個人的臉都瞧了一遍。
- **無名**　〔S258〕老伯說這是最後一盤。下完了，各位回各位的年月，我回我的被窩。……我記性不好，醒了多半要忘。各位莫怪。
- **旁白**　〔S259〕石上還空著一行的地方。求敗提起那柄刻字的劍，瞧了一瞧，沒有刻，將劍輕輕放在石旁。最後一行，他沒有刻。

### 各境界共用

- **旁白**　〔S260〕這一輪沒有下完。臺邊的石上，沒有多一行字。

## 夢醒

> 一輪結束，少年醒來。先接 CLOSING 一句（勝：請回吧；敗：盒蓋合上），再接按境界取的一段 FRAGMENTS（第一段為第一重境界）。

- **旁白**　〔S261〕那一聲「請回吧」猶在耳邊。少年醒了。
- **旁白**　〔S262〕盒蓋合上的那一聲猶在耳邊。少年醒了。

### 第一重・利劍境界

- **旁白**　〔S263〕有甚麼濕熱的東西在舔他的臉，一下，又一下。是家裡的狗。夢只剩一點影子：一張棋臺，一個老人。他的手指還拈著，像拈著一枚棋子。

### 第二重・軟劍境界

- **旁白**　〔S264〕鍋鏟碰著鐵鍋，嚓，嚓。有飯香。娘在灶前做飯。他拾起灶邊一根柴枝，不知怎地，手腕一抖，挽了個劍花。

### 第三重・重劍境界

- **旁白**　〔S265〕娘在喊他起來，喊的是他的名字。這兩個字他聽了十幾年，此刻聽來竟有些生疏，倒似有人一直叫他別的甚麼。他到屋後翻出一柄生了鏽的舊劍。

### 第四重・木劍境界

- **旁白**　〔S266〕雞啼了，窗紙發白，被窩外頭好冷。他不想起來：他想回去把那盤棋下完。那柄劍已經磨亮了，擱在枕邊。

### 第五重・無劍境界

- **旁白**　〔S267〕被窩裡，他的手還握著，像剛握過許多人的手。他握住枕邊的劍，走到屋外，天還沒有亮。
