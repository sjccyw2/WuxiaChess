# 《一念江湖》（暫名）世界觀設定

> 版本：v0.3（2026-11-20）
> 用途：供協作 agent 接手細化。本文件自成一體，不需要其他上下文。

## 0. 給接手 agent 的說明

**已定案（請勿更動，除非製作人明確要求）：**

- 局主是獨孤求敗，他以「劍解」成仙，因一念未了而卡在仙品最末。
- 玩家是年輕時的獨孤求敗（無名少年）。
- 英雄與反派都是本尊的「一念」，不是複製品；歷史不可更改。
- 第 1 至第 6 節的規則與因果鏈。

**已否決（請勿重提）：**

- 「爛柯」這個名字（粵語讀來不雅）。
- 玩家是神鵰。神鵰只作為引路的 NPC。
- 英雄是「拓本／複製品」的設定。

**尚未定案：** 見第 9 節。

**寫作原則：**

- 不與金庸原著的既有事實衝突；本設定只「補白」，不「改寫」。
- 每一項遊戲機制都要有世界內的解釋；新增機制時請先補上解釋。
- 基調是金庸式的「求不得」與「俠」，不是修仙爽文。成仙只是時間機制的解釋，不要引入法術體系。

## 1. 遊戲概要（機制前提）

類型是「聖火降魔錄式格子戰棋 + Roguelite」，登場角色為既有武俠人物（以金庸人物為主）。

| 機制 | 內容 |
|---|---|
| 一輪流程 | 10 張地圖，每張有不同的反派 |
| 開局 | 隨機獲得 3 名英雄 |
| 招募 | 在輪中達成特定條件可獲得新英雄 |
| 上場人數 | 每場戰鬥最多 5 名英雄 |
| 養成 | 每名英雄有自己的技能樹與裝備 |
| 經濟 | 商店系統、老虎機系統 |
| 局外主線 | 玩家在多輪遊玩中逐步揭開世界的真相 |

世界觀必須解決的核心問題：**不同時代的人物為何能同處一個時空，以及上述機制為何合理。**

---

## 2. 一句話

一個求敗千年而不可得的劍仙，把千年的高手請進自己的劍境，只為造出一個能贏他的對手；而那個對手，是年輕時的他自己。

---

## 3. 獨孤求敗的故事

1. **無名少年。** 原著從未交代他的本名，「求敗」是後來的自號。少年時用的是一柄利劍。
2. **無敵。** 利劍、紫薇軟劍、玄鐵重劍、木劍，一路打到天下無人可敵。他改名「求敗」，隱居深谷，以鵰為友。
3. **無劍之後。** 再無外敵，最後一個對手是自己的勝負心。這一劍他斬不下去，因為「想輸」本身就是他唯一贏不了的東西。
4. **劍解成仙。** 道教尸解之法中有一種「劍解」：留劍代身，人已仙去。原著的劍塚裡埋的是劍，不是人，正是此事的痕跡。
5. **卡住的仙。** 尸解仙是仙品最末一等。他因一念未了不得飛升，「求一敗」從心願變成了劫。他要的不是勝利，是解脫。
6. **開局。** 他開出一片不在時間之內的天地，稱為「劍境」，在其中設下十局。

---

## 4. 劍境的規則

### 4.1 為何能跨越時代

成仙之後，他不在時間之內。棋譜上，第一手與第二百手同在一張紙上；千年江湖於他，就是攤開的一張譜。所以在他之前的人（如蕭峰）與在他之後的人（如張無忌、令狐冲），他都看得見。

### 4.2 三條仙規

他是最末等的仙，能力有限。以下三條是整個設定的硬規則。

| 仙規 | 內容 | 它解釋了什麼 |
|---|---|---|
| 一、只借一念 | 高手在生死關頭或頓悟邊緣會有一瞬出神。他只能請這「一念」入劍境，不能動人的肉身。局中千日，世上一瞬 | 歷史不變；英雄是本尊；在局中戰死只是「夢醒」，回到原來那一瞬 |
| 二、只見入道者 | 武學未到一定境界的人，他看不見 | 來的都是一代高手，反派亦然 |
| 三、仙凡之隔 | 他不能直接對凡人出手。對方須走完十局「登階」，才能站到他面前 | 為何有十關；為何他自己執黑、以反派為磨劍石 |

兩個例外：

- **少年獨孤。** 少年尚未入道，但那是他自己的一念，自己總看得見。
- **韋小寶。** 他不會武功，仙人看不見他。他是唯一不請自來的人（見第 7 節）。

### 4.3 記憶與功力

- **境中之事留在境中。** 人在劍境裡記得之前每一次入境的事；一旦夢醒回到原來的時空，全部忘記，只帶走一點領悟。
- **功不隨念。** 每次入境，來的都是同一瞬的那一念，所以功力每輪從頭修起；留在境中的只有記憶與情誼。

由此得到兩個效果：

- 英雄之間、英雄與玩家之間的關係可以跨輪累積。
- 原著中每一次臨陣頓悟，都可以解釋為「剛從劍境回來」。

### 4.4 英雄與反派為何而戰

- **英雄。** 他們是從各自的絕境被請來的，例如聚賢莊的蕭峰、光明頂的張無忌。走完十局，才能帶著那一悟回去活命。入局出於自願；入了局便守局規，聽執子之人號令。
- **反派。** 同樣是本尊的一念，只是請來的那一瞬不是「悟」而是「執」，例如慕容復的復國、岳不群的偽善、歐陽鋒的「我是誰」。獨孤求敗親自執黑，以他們為磨劍石。十種執念，都是他自己勝負心的倒影。

---

## 5. 玩家是誰

**玩家就是那個無名少年，即弱冠之前的獨孤求敗。**

### 5.1 因果鏈

1. 劍仙查遍千年，沒有一個時代養得出能贏他的人。唯一夠格的對手只有自己。
2. 他把少年時的自己請入劍境執白子，再配上千年的高手，湊成一場公平的對局。
3. 少年每輸一次，就夢醒回去，忘了一切，只帶走領悟，於是越來越強。
4. 少年在劍境裡見過千年的武功，日後創出能「破盡天下武學」的獨孤九劍，連後世才出現的武功都能破。
5. 少年因此打遍天下無敵手，改名求敗，隱居，劍解，成為卡住的劍仙，回到第 1 步。

### 5.2 這個設定的三層意思

- **悲劇。** 他求敗的每一次嘗試，恰恰造就了自己的無敵。
- **孤獨。** 夢醒即忘。他一生獨來獨往，卻總覺得曾與人並肩。他真正在「求」的，其實是那群記不起來的同伴。
- **自洽。** 劍仙不記得自己年輕時曾被請入劍境，因為出境即忘。這是一個穩定的時間閉環。

### 5.3 玩家在盤上的位置

少年是「執子之人」，不入盤，所以平時不上場作戰。直到第十一局才破例下場（見第 8 節）。

## 6. 機制對應表

| 遊戲機制 | 世界內的解釋 |
|---|---|
| 格子戰棋 | 劍仙設下的棋盤；少年執白，劍仙執黑 |
| 開局隨機三人 | 「帖發千張，應者隨緣」：每輪只有三人應帖 |
| 上場上限五人 | 盤上只有東、南、西、北、中五個「絕位」。後世華山論劍排出五絕，只是這張棋盤落在人間的影子 |
| 十張地圖 | 一場「十番棋」，也是凡人見仙必須登的十級階（仙規三）。每局一位局主，各代表一種「執」 |
| 達成條件得新英雄 | 「了緣」：在局中重演某人的因果，他才會應帖而來 |
| 技能樹 | 經脈圖即生平：每個節點是一段際遇，升級等於重走他的一生；分支是「他沒走的那條路」 |
| 每輪養成歸零 | 功不隨念（4.3） |
| 英雄戰死 | 夢醒，回到原來那一瞬，本輪退場 |
| 裝備 | 器物沒有「念」，是真品墜入劍境 |
| 商店與老虎機 | 韋小寶的「通吃坊」；三顆骰子就是三個轉輪 |
| 局外成長 | 少年累積的「悟」，以石刻的形式留在劍塚（大本營） |
| 難度階梯 | 劍塚五境：利劍、軟劍、重劍、木劍、無劍，每升一境改一條規則（例：木劍境裝備減效，無劍境禁用裝備） |
| 長線收集 | 獨孤九劍九式（見第 8 節） |

**「了緣」條件示例**（須呼應原著）：

- 虛竹：犧牲一名己方單位後仍取勝（珍瓏棋局的自填一氣）。
- 石破天：整場不使用任何技能（不識字，故無招）。
- 楊過：一名單位死守同一格十六回合（十六年之約）。
- 蕭峰：在以寡敵眾的地圖中保住指定的非戰鬥人物。

**裝備是第一個破綻。** 倚天劍與玄鐵重劍同時出現，而前者本是後者熔鑄而成。玩家與英雄由此察覺此地不在時間之內。

## 7. 劍境中的非戰鬥人物

| 人物 | 身分 | 作用 |
|---|---|---|
| 神鵰 | 獨孤求敗唯一的朋友 | 引路人與大本營的同伴，一如牠當年引楊過入谷。牠從第一天就認得玩家，這是伏筆 |
| 韋小寶 | 《鹿鼎記》結尾失蹤後摸進劍境的活人 | 經營「通吃坊」（商店與賭坊）。圍棋沒有運氣，他的骰子是局主唯一沒算到的變數，也是結局的鑰匙之一。他是最後一個時代的人，可以告訴英雄們江湖後來的下場 |
| 獨孤求敗（劍仙） | 局主、最終對手 | 每當玩家走完十局而落敗，他只說一句「還不夠」，然後重開 |

## 8. 跨輪主線：五卷

| 卷 | 解鎖時機 | 玩家得知 | 新開放 |
|---|---|---|---|
| 一〈英雄帖〉 | 初期 | 表層故事：有劍仙設下十局，勝者得一悟。眾人以為是一場夢，各以為身在自己的年代 | 基本系統 |
| 二〈一念〉 | 首次走完十局、敗於局主 | 每個人都是借來的一瞬，贏了才回得去。裝備的破綻在此揭開 | 每位英雄的「心結」任務 |
| 三〈劍解〉 | 帶楊過或令狐冲見到局主 | 局主是獨孤求敗；劍塚無屍；他是卡住的仙；反派是他的磨劍石 | 劍塚五境 |
| 四〈無名〉 | 帶楊過打通高境 | 玩家就是他 | 獨孤九劍 |
| 五〈求敗〉 | 全員心結已解 | 他為何永遠輸不了，以及他缺的是什麼 | 第十一局 |

### 8.1 卷四的伏筆

- 神鵰從第一天就認得玩家。
- 劍塚每一境的石刻，都是玩家的筆跡。
- 石刻的落款平時模糊不清；揭曉時顯現的，是玩家開局時輸入的名字。
- 局外成長的路徑（利劍、軟劍、重劍、木劍、無劍）正是他一生的五個階段。

### 8.2 敘事引擎：跨代對話

開局隨機三人，等於每輪抽到不同的跨代組合。對話本身是收集品，也是揭露世界觀的主要管道。示例：

- 百歲張三丰遇見少女郭襄。
- 段譽遇見自己的後人一燈。
- 楊過與令狐冲發現彼此師出同源（都是獨孤求敗的傳人）。
- 張無忌向郭靖問起刀劍中藏的秘密。

### 8.3 第十一局

- 玩家親自下場，成為盤上第六人，打破五人上限。規則被打破的那一刻，就是劍仙的敗。
- 玩家的技能樹就是獨孤九劍：總訣式、破劍式、破刀式、破槍式、破鞭式、破索式、破掌式、破箭式、破氣式。九式由歷輪累積解鎖，例如擊敗夠多用劍的敵人才得「破劍式」。
- 劍仙為何一直輸不了：少年每次帶回去的只有劍上的領悟，而劍上的東西劍仙全都有。
- 劍仙最終輸給三樣他沒有的東西：同伴（情）、骰子（運），以及少年這一次不肯忘記的決心。

### 8.4 結局

劍仙得一敗，飛升而去。少年可以選擇：

- **歸去（正結局）。** 破例帶著記憶回去，明知孤獨仍走完那條路。因為他若不成為獨孤求敗，楊過就得不到重劍，令狐冲就學不到九劍。從此「求敗」不再是絕望，而是他與同伴的一個約定：谷的盡頭有人在等他。
- **留下（可作無盡模式）。** 留在劍境，為江湖保住一個容身之處。

## 9. 尚未定案

1. **遊戲名稱。** 候選：《一念江湖》（暫用）、《求敗》、《劍解》。
2. **十局局主名單。** 每局對應哪一種「執」、哪一位反派、哪一個原著場景；反派是否每輪隨機抽換。
3. **英雄名單與各自的入境時刻。** 每人是從原著哪一瞬被請來的；同一人是否有多個版本（如少年郭靖與襄陽郭靖）。
4. **每位英雄的「心結」任務與「了緣」條件。**
5. **反派可否被化解而加入。** 原著中鳩摩智、裘千仞等人最終悔悟，可作招募來源。
6. **韋小寶如何進入劍境。** 目前留白，可作為一條支線謎題。
7. **劍塚五境各自修改哪一條規則。**
8. **金庸以外的人物。** 古龍、梁羽生等作者的人物可設定為「另一張盤」，尚未展開。
