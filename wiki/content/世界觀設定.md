## 1. 遊戲概要（機制前提）

類型是「聖火降魔錄式格子戰棋 + Roguelite」，登場角色為既有武俠人物（以金庸人物為主）。

| 機制 | 內容 |
|---|---|
| 一輪流程 | 10 張地圖，每張有不同的反派 |
| 開局 | 隨機獲得 3 名英雄 |
| 招募 | 在輪中達成特定條件可獲得新英雄 |
| 上場人數 | 每場戰鬥最多 5 名英雄 |
| 養成 | 每名英雄有自己的技能樹與裝備 |
| 經濟 | 商店系統、老虎機系統 |
| 局外主線 | 玩家在多輪遊玩中逐步揭開世界的真相 |

世界觀必須解決的核心問題：**不同時代的人物為何能同處一個時空，以及上述機制為何合理。**

## 2. 一句話

一個求敗千年而不可得的劍仙，把千年的高手請進自己的劍境，只為造出一個能贏他的對手；而那個對手，是年輕時的他自己。

---

## 3. 獨孤求敗的故事

1. **無名少年。** 原著從未交代他的本名，「求敗」是後來的自號。少年時用的是一柄利劍。
2. **無敵。** 利劍、紫薇軟劍、玄鐵重劍、木劍，一路打到天下無人可敵。他改名「求敗」，隱居深谷，以鵰為友。
3. **無劍之後。** 再無外敵，最後一個對手是自己的勝負心。這一劍他斬不下去，因為「想輸」本身就是他唯一贏不了的東西。
4. **劍解成仙。** 道教尸解之法中有一種「劍解」：留劍代身，人已仙去。原著的劍塚裡埋的是劍，不是人，正是此事的痕跡。
5. **卡住的仙。** 尸解仙是仙品最末一等。他因一念未了不得飛升，「求一敗」從心願變成了劫。他要的不是勝利，是解脫。
6. **開局。** 利劍、軟劍、重劍、木劍、無劍，每一步都多放下一點手中之物。無劍之後，連自己的手也放下，剩下的只有局。他開出一片不在時間之內的天地，稱為「劍境」，在其中設下十局。這盤棋是他的第六柄劍（見 4.5）。

## 4. 劍境的規則

### 4.1 為何能跨越時代

成仙之後，他不在時間之內。棋譜上，第一手與第二百手同在一張紙上；千年江湖於他，就是攤開的一張譜。所以在他之前的人（如蕭峰）與在他之後的人（如張無忌、令狐冲），他都看得見。

### 4.2 三條仙規

他是最末等的仙，能力有限。以下三條是整個設定的硬規則。

| 仙規 | 內容 | 它解釋了什麼 |
|---|---|---|
| 一、只借一念 | 高手在生死關頭或頓悟邊緣會有一瞬出神。他只能請這「一念」入劍境，不能動人的肉身。局中千日，世上一瞬 | 歷史不變；英雄是本尊；在局中倒下不是真死，一輪終了才「夢醒」，回到原來那一瞬 |
| 二、只見入道者 | 武學未到一定境界的人，他看不見 | 來的都是一代高手，反派亦然 |
| 三、仙凡之隔 | 他不能直接對凡人出手。對方須走完十局「登階」，才能站到他面前 | 為何有十關；為何他自己執黑、以反派為磨劍石 |

兩個例外：

- **少年獨孤。** 少年尚未入道，但那是他自己的一念，自己總看得見。他入境的那一瞬也不是生死關頭，而是入睡（見 5.4）。
- **韋小寶。** 他不會武功，仙人看不見他。他是唯一不請自來的人（見第 7 節）。

### 4.3 記憶與功力

- **念不帶痕。** 每次入境，來的都是同一瞬的那一念，所以每一輪他都是第一次來，不記得之前入境的事。
- **功不隨念。** 同一個道理，功力每輪從頭修起。
- **境中留痕。** 劍境不在時間之內，發生過的事留在境裡：石刻、器物、境中活人的記性。人只剩一點說不出來由的似曾相識。
- **夢醒只帶走一悟。** 回到原來的時空，連似曾相識也沒有了，只帶走一點領悟。

由此得到兩個效果：

- 英雄之間、英雄與玩家之間的情誼不靠記憶累積，而是以「面善」的形式，一輪比一輪浮得更上來。
- 原著中每一次臨陣頓悟，都可以解釋為「剛從劍境回來」。

### 4.4 英雄與反派為何而戰

- **英雄。** 他們是從各自的絕境被請來的，例如聚賢莊的蕭峰、光明頂的張無忌。走完十局，才能帶著那一悟回去活命。入局出於自願；入了局便守局規，聽執子之人號令。
- **反派。** 同樣是本尊的一念，卻不是應帖而來，是獨孤求敗親手落下的黑子。他的一道劍意壓在他們心頭，叫他們非戰不可：余滄海提不起搶劍譜的心思，田歸農的腳自己往前走，岳不群來不及找出劍的名目。他們覺得出這個念頭不是自己的，卻掙不開，也說不出是誰。
- **為何要借他們的手。** 仙凡之隔，他不能親自對凡人出手（仙規三），所以借反派為磨劍石。他要的是一敗：黑子輸了，這一手便算他輸，劍意自然收回，局主醒來，回到原來那一瞬；黑子贏了，他還沒有輸，所以不放人。
- **遊戲內不點破。** 局中人只說「一道劍意」「那個念頭」「落子的人」，沒有人說得出是誰（見第 0 節 v0.6）。

### 4.5 為何是一盤棋

獨孤求敗是劍客，不是棋手。他以棋局求敗，理由有五條。

- **九劍練的是眼，不是手。** 獨孤九劍不靠力大，也不靠手快，靠的是「料敵機先」：對方的招還沒使出來，已經看見破綻在哪裡。在盤外看全局、算對手下一步，正是這門劍法真正用功的地方。棋盤不是劍的替代品，是這雙眼睛看出去的樣子。
- **他只剩這一種打法。** 仙凡之隔，他不能對凡人出手；請來的又只是一念，沒有肉身。沒有手、沒有身，剩下的只有「意」的較量，那就是一盤棋。
- **指點旁人出手，在原著裡本來就是比武。** 風清揚傳劍的第一課，是站在一旁，叫令狐冲照他說的次序出招，去鬥田伯光。洪七公與歐陽鋒在華山絕頂力竭之後，最後一場比試是各自口述招式，由楊過代為施展。無崖子擺下珍瓏棋局，為的是挑一個武學傳人；來破局的高手，個個敗在自己的執念上。
- **一場比劍，考不出他沒有的東西。** 比劍只考劍上的功夫，而劍上的功夫他全都有。能贏他的人得做到兩件事。一是在盤外看遍千年的武功，日後才創得出破盡天下武學的九劍。二是讀得懂他：他親自執黑，這十局就是他的十次出手。他的劍沒有破綻，心卻有：他按著十位局主非戰不可，那一股不肯罷手的勁，正是他自己的勝負心。
- **棋局是一個人贏不了的格式。** 這一條不是他的本意。少年不能入盤，只能靠別人取勝；信人、託人、被人所託，正是「獨孤」一生沒有的東西，也是最後贏他的東西（第 8 節）。

## 5. 玩家是誰

**玩家就是那個無名少年，即弱冠之前的獨孤求敗。**

### 5.1 因果鏈

1. 劍仙查遍千年，沒有一個時代養得出能贏他的人。唯一夠格的對手只有自己。
2. 他把少年時的自己請入劍境執白子，再配上千年的高手，湊成一場公平的對局。
3. 少年每輸一次，就夢醒回去，忘了一切，只帶走領悟，於是越來越強。
4. 少年在劍境裡見過千年的武功，日後創出能「破盡天下武學」的獨孤九劍，連後世才出現的武功都能破。
5. 少年因此打遍天下無敵手，改名求敗，隱居，劍解，成為卡住的劍仙，回到第 1 步。

### 5.2 這個設定的三層意思

- **悲劇。** 他求敗的每一次嘗試，恰恰造就了自己的無敵。
- **孤獨。** 夢醒即忘。他一生獨來獨往，卻總覺得曾與人並肩。他真正在「求」的，其實是那群記不起來的同伴。
- **自洽。** 劍仙不記得自己年輕時曾被請入劍境，因為出境即忘。這是一個穩定的時間閉環。

### 5.3 玩家在盤上的位置

少年是「執子之人」，不入盤，所以平時不上場作戰。直到第十一局才破例下場（見第 8 節）。

### 5.4 睜眼與闔眼

- **他是睡著了才來的。** 英雄的一念出於生死關頭；少年的一念出於入睡。他在自己的年月裡睡著了，神魂被請進劍境。
- **睜眼。** 每一輪從少年睜開眼開始。他以為自己醒了，其實是剛睡著。英雄以為這是夢，他卻以為這是醒，兩邊都只說對一半。
- **闔眼。** 每一輪結束，他闔上眼，隱約感到真實世界的動靜：狗在舔他的臉，母親在灶前做飯。然後他真的醒了，忘了一切，只帶走領悟。
- **這些動靜是他僅有的身世。** 原著沒有交代他的少年時代，本設定也只給到這些聲音、氣味與觸感。細節見《單輪劇本》。

## 6. 機制對應表

| 遊戲機制 | 世界內的解釋 |
|---|---|
| 格子戰棋 | 劍仙設下的棋盤；少年執白，劍仙執黑。九劍練的是料敵機先的眼力，棋盤就是這雙眼睛看出去的樣子（4.5） |
| 開局隨機三人 | 「帖發千張，應者隨緣」：每輪只有三人應帖。帖不署名 |
| 上場上限五人 | 盤上只有東、南、西、北、中五個「絕位」。後世華山論劍排出五絕，只是這張棋盤落在人間的影子 |
| 十張地圖 | 一場「十番棋」，也是凡人見仙必須登的十級階（仙規三）。每局一位局主、一位副手（v0.8 起，有的局多一位局主或副手，並有援軍），都是他落下的黑子，給他的劍意壓著，非戰不可（4.4）。局與局互不相干，次序可以抽換；日後地圖增多，每輪從中抽選，只有最後一局固定 |
| 勝局得新英雄；支線另有獎賞 | 帖發千張，應者隨緣。還有人持帖在盤外觀望。v0.8 起，不是最後一局時每勝一局便多一人肯來，支線改為另得獎賞（賞銀、武學點或武譜）；這在世界內怎麼說，待故事細化時重寫。原先的說法是：這一局點亮了引路燈，或贏得快、贏得一人不倒，便多一人肯來。各英雄專屬的「了緣」（在局中重演某人的因果）留待日後 |
| 技能樹 | 經脈圖即生平：每個節點是一段際遇，升級等於重走他的一生；分支是「他沒走的那條路」 |
| 每輪養成歸零 | 功不隨念（4.3） |
| 英雄倒下 | 「提子」：離盤一局，下一局再落。只有領隊（這一輪的「眼」）倒下，眾人才一齊夢醒，這一輪結束 |
| 裝備 | 器物沒有「念」，是真品墜入劍境 |
| 商店與老虎機 | 韋小寶的「通吃坊」；三顆骰子就是三個轉輪 |
| 局外成長 | 少年累積的「悟」，以石刻的形式留在劍塚（大本營） |
| 難度階梯 | 劍塚五境：利劍、軟劍、重劍、木劍、無劍，每升一境改一條規則（例：木劍境裝備減效，無劍境禁用裝備） |
| 長線收集 | 獨孤九劍九式（見第 8 節） |

**「了緣」條件示例**（須呼應原著；尚未做進遊戲）：

- 虛竹：犧牲一名己方單位後仍取勝（珍瓏棋局的自填一氣）。
- 石破天：整場不使用任何技能（不識字，故無招）。
- 楊過：一名單位死守同一格十六回合（十六年之約）。
- 蕭峰：在以寡敵眾的地圖中保住指定的非戰鬥人物。

**裝備是第一個破綻。** 倚天劍與玄鐵重劍同時出現，而前者本是後者熔鑄而成。玩家與英雄由此察覺此地不在時間之內。

## 7. 劍境中的非戰鬥人物

| 人物 | 身分 | 作用 |
|---|---|---|
| 神鵰 | 獨孤求敗唯一的朋友 | 引路人與大本營的同伴，一如牠當年引楊過入谷。牠從第一天就認得玩家，這是伏筆 |
| 韋小寶 | 《鹿鼎記》結尾失蹤後摸進劍境的活人 | 經營「通吃坊」（商店與賭坊）。圍棋沒有運氣，他的骰子是局主唯一沒算到的變數，也是結局的鑰匙之一。他是最後一個時代的人，可以告訴英雄們江湖後來的下場 |
| 獨孤求敗（劍仙） | 局主、最終對手 | 每當玩家走完十局而落敗，他只說一句「還不夠」，然後重開 |

## 8. 跨輪主線：五卷

| 卷 | 解鎖時機 | 玩家得知 | 新開放 |
|---|---|---|---|
| 一〈英雄帖〉 | 初期 | 表層故事：有人設下十局，勝者得一悟。帖不署名，沒有人知道設局的是誰。眾人以為是一場夢，各以為身在自己的年代 | 基本系統 |
| 二〈一念〉 | 首次走完十局、敗於局主 | 每個人都是借來的一瞬，贏了才回得去。裝備的破綻在此揭開 | 每位英雄的「心結」任務 |
| 三〈劍解〉 | 帶楊過或令狐冲見到局主 | 局主是獨孤求敗；劍塚無屍；他是卡住的仙；反派是他的磨劍石 | 劍塚五境 |
| 四〈無名〉 | 帶楊過打通高境 | 玩家就是他 | 獨孤九劍 |
| 五〈求敗〉 | 全員心結已解 | 他為何永遠輸不了，以及他缺的是什麼 | 第十一局 |

### 8.1 卷四的伏筆

- 神鵰從第一天就認得玩家。
- 劍塚每一境的石刻，都是玩家的筆跡。
- 石刻的落款平時模糊不清；揭曉時顯現的，是玩家開局時輸入的名字。
- 局外成長的路徑（利劍、軟劍、重劍、木劍、無劍）正是他一生的五個階段。

### 8.2 敘事引擎：跨代對話

開局隨機三人，等於每輪抽到不同的跨代組合。對話本身是收集品，也是揭露世界觀的主要管道。示例：

- 百歲張三丰遇見少女郭襄。
- 段譽遇見自己的後人一燈。
- 楊過與令狐冲發現彼此師出同源（都是獨孤求敗的傳人）。
- 張無忌向郭靖問起刀劍中藏的秘密。

### 8.3 第十一局

- 玩家親自下場，成為盤上第六人，打破五人上限。規則被打破的那一刻，就是劍仙的敗。
- 玩家的技能樹就是獨孤九劍：總訣式、破劍式、破刀式、破槍式、破鞭式、破索式、破掌式、破箭式、破氣式。九式由歷輪累積解鎖，例如擊敗夠多用劍的敵人才得「破劍式」。
- 令狐冲的技能樹如今也有總訣式、破劍式、破箭式、破氣式與獨孤九劍。兩者重疊無妨（製作人已定）：少年九式俱全，各式的效果可與令狐冲的不同。
- 劍仙為何一直輸不了：少年每次帶回去的只有劍上的領悟，而劍上的東西劍仙全都有。
- 劍仙最終輸給三樣他沒有的東西：同伴（情）、骰子（運），以及少年這一次不肯忘記的決心。

### 8.4 結局

劍仙得一敗，飛升而去。少年可以選擇：

- **歸去（正結局）。** 破例帶著記憶回去，明知孤獨仍走完那條路。因為他若不成為獨孤求敗，楊過就得不到重劍，令狐冲就學不到九劍。從此「求敗」不再是絕望，而是他與同伴的一個約定：谷的盡頭有人在等他。
- **留下（可作無盡模式）。** 留在劍境，為江湖保住一個容身之處。

## 9. 尚未定案

1. **遊戲名稱。** 候選：《一念江湖》（暫用）、《求敗》、《劍解》。
2. **十局局主名單，與每一局各自的故事。** 目前十局共用同一個前提：局主給劍意壓著，非戰不可。每局對應哪一位反派、哪一個原著場景、與哪位英雄有恩怨，日後再添。現有十局的配對見《單輪劇本》；局的次序已可抽換，日後增加地圖後改為每輪隨機抽選。
3. **英雄名單與各自的入境時刻。** 每人是從原著哪一瞬被請來的；同一人是否有多個版本（如少年郭靖與襄陽郭靖）。
4. **每位英雄的「心結」任務與「了緣」條件。**
5. **反派可否被化解而加入。** 原著中鳩摩智、裘千仞等人最終悔悟，可作招募來源。
6. **韋小寶如何進入劍境。** 目前留白，可作為一條支線謎題。
7. **劍塚五境各自修改哪一條規則。**
8. **金庸以外的人物。** 古龍、梁羽生等作者的人物可設定為「另一張盤」，尚未展開。
